# synthetic-quad STL fixtures

- **Provenance**: authored in this repository; the binary file was generated from
  the same two triangles with a small Python `struct` script.
- **Licence**: same as the repository (Apache-2.0 OR MIT).
- **Synthetic**: yes. No vendor, customer or third-party data.
- **Content**: a unit square as two flat facets, one ASCII file
  (`synthetic-quad.stl`) and one binary file (`synthetic-quad-binary.stl`) with
  the standard 80-byte header and little-endian facet count.
- **Known limits**: no units, no colours, no material data. These fixtures pin
  the ASCII/binary parity contract only; they are not compatibility evidence.
