# Synthetic ACIS fixtures

These `.sat` payloads are **synthetic, authored in this repository**. They were
generated by `cargo run -p cad-import-acadrust --example generate_acis_fixtures`
from acadrust's documented primitive builders (and, for `box-with-square-hole`,
from the same ACIS record layout by hand). No vendor drawing, no AutoCAD output
and no third-party sample is included.

They pin the neutral B-rep lift and the documented tessellation subset in
`docs/kernel-acis.md`; they are **not** ACIS/AutoCAD compatibility evidence.

| File | Intent |
|---|---|
| `cube.sat` | six planar faces, one loop each → closed planar mesh |
| `box-with-square-hole.sat` | planar faces with inner loops (holes) → closed mesh |
| `cylinder.sat` | two planar circular caps + one full cylindrical side |
| `sphere.sat` | one loop-less spherical face (full parameter domain) |
| `cone-unsupported.sat` | planar base + unsupported cone side → `Partial`/missing face |

Regenerate with:

```bash
cargo run -p cad-import-acadrust --example generate_acis_fixtures -- fixtures/acis
python3 - <<'PY'
import json, hashlib, pathlib
m = json.loads(pathlib.Path("fixtures/manifest").read_text())
for f in m["fixtures"]:
    h = hashlib.sha256(pathlib.Path(f["path"]).read_bytes()).hexdigest()
    assert h == f["sha256"], (f["path"], h)
print("manifest hashes OK")
PY
```
