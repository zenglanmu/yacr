# 代理支持（仅基础代码与合成测试，未真实验收）

ProxyRecordDecoder/ProxyPlayer 接收公开 graphic_data；不把 raw_dwg_data 当代理缓存。
当前已有基础 framing、部分记录回放及合成测试；源码中的 opcode/格式假设仍需逐项
对照 acadrust 公开格式与授权真实样本，不能以合成数据自洽证明格式正确。
没有天正/探索者真实样本，不声明兼容。

接手必须验证记录边界、长度溢出、记录/顶点/状态栈限制、格式版本；维护样式/填充/变换栈。
未知状态影响后续输出时保守标记不完整。普通语义实体成功后不得叠画代理。
源 handle/类名/软件/版本/字节长度与完整性应进入对象报告；不得伪造缺失图形。
代理展开进入普通表示/索引/批处理，不为每条指令创建 draw call。

样本至少包括有缓存、无缓存、仅包围盒、未知指令、损坏缓存和不同软件/实体类别。
PROXYGRAPHICS=1 只能由具有生成能力的源软件重新保存，不能恢复不存在的数据。
