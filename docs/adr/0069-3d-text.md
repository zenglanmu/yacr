# ADR-0069：三维文字（3D Text）

- 状态：**已接受（决策，2026-11-27）**；**已实现（2026-11-27，已填充字形网格挤出 + 一步撤销；无真实 GUI/GPU 证据）**
- 关联：ADR-0038（网格/文本显示）、`TXTEXP` 的字体 outline 接缝、ADR-0067/0068（同属“工具不再 pending”）

## 背景

SketchUp 的 3D Text 对话框把字符串变成**可挤出的字形几何**（默认 1 单位厚），可再推拉/编辑。
本仓库已有：

- `FontEngine`（`cad-representation`）把文本整形为世界坐标轮廓
  （`ShapedText.outlines`）以及**已填充字形面**（`ShapedText.meshes`，`fill_rings` 的 even-odd
  结果，孔洞已扣除）；
- `TXTEXP` 已通过 `install_outline_fonts` 的进程级引擎读这份 outline 数据（宿主安装）；
- 网格实体 `SemanticGeometry::Mesh` + `AcDbSubDMesh` 类型键、`commit_new_entity_typed` 一次事务/
  一步撤销的创建漏斗；
- 没有字体对话框、旋转/对齐 UI，也没有 guide/材质系统。

因此 3D Text 可以诚实地实现为“把**显示已经算好的字形面**挤出成一个网格”，而不用自造第二条
字体/三角化路径。

## 决策

### D1 命令而非对话框

`TEXT3D <x> <y> <z> <height> <extrusion> <font|-> <text…>`：

- 五个有限数（原点、字高、挤出厚度；高/厚必须严格为正，原点有限）；
- 一个字体 token（`-` = 引擎的默认/回退链），剩余整行是字符串（保留内部空格、拒绝换行、长度受
  `MAX_TOOL_TEXT_CHARS` 限制）；
- 没有旋转/对齐/斜体/描边输入：v1 固定在 XY 平面、`+Z` 挤出、Left/Baseline 对齐，命令文档与
  覆盖表都写明。

### D2 几何 = 显示字形面的挤出

- 形状来自 `FontEngine::shape(...)`（显式字体）或 `shape_unstyled`（默认/回退链），取
  `ShapedText.meshes`——每个字形一个**已填充**网格，孔洞（o/e 的内圈）已经按 even-odd 去除；
- 每个字形的上下盖直接复制该网格的三角形（下盖反向、法向 −Z；上盖原序、法向 +Z）；
- 每个**边界边**（只被一个三角形使用的无向边）生成一段侧墙四边形，法向取边的右侧（填充三角形
  一致 CCW，因此侧墙朝外）；
- 结果是一个 `AcDbSubDMesh`（无 `face_sources`/UV/材质），一次事务/一步撤销，并且与显示使用同一份
  填充，不会出现“显示有孔、挤出实体却填满”的第二套真值。

### D3 具名拒绝（都不写文档）

`text3d.payload` / `invalid_point` / `invalid_size` / `invalid_text` /
`font_unavailable`（没有安装引擎或字体无法整形）/ `no_outlines` /
`not_solid`（SHX 描边字体或填充失败，没有已填充字形面）/ `budget`
（超过 131 072 三角形或 100 000 顶点）。Viewer 模式按 `PermissionDenied` 拒绝。

### D4 UI

概念域工具栏与 Draw 菜单的 3D Text 从 `pending` 变成 `command: 'TEXT3D'` 的真实命令，提示键说明
完整参数与边界；catalog 增加 `TEXT3D` 行。它仍需要命令行参数（没有对话框），与 `MSTRETCH` 等
payload/参数型命令同属“命令可用、无专用对话框”。

## 不在本 ADR 范围

- 字体选择对话框、旋转/对齐/斜体/描边、字距/行距；
- 截面/圆角/倒角、可编辑的参数化文字、材质/纹理；
- 把 3D Text 再参与布尔/推拉以外的特殊语义；
- 真实 GUI/GPU 交互与其它载体运行时。

## 后果

- 新增一个 `CommandId`、一条 typed grammar 与一个可选字体 token；**无格式档位变化**
  （保存的是普通网格行，现有 `.ymodel` 已能承载）。
- 挤出的是显示字形面：SHX 描边字体无法成为实体，明确拒绝而不是扫成带状面。
- 长字符串受字形/三角形预算约束；超限按名拒绝，绝不截断。
