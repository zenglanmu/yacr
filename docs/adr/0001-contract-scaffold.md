# ADR 0001：可编译契约框架与显式占位

状态：采用。范围：本次用户要求“框架、关键结构体和方法、完整模块空实现”。

问题：规范描述完整产品，但当前缺跨端 GPU/UI 证据、授权 DWG/字体和上游审计。
选择：保留规范 23 包的职责与单向依赖，定义自有数据契约；未完成操作统一返回
CadError::NotImplemented，而非 panic/todo!/空成功。结构读取和安全基础校验可真实实现。

候选：立即实现完整业务（超出本次范围）；只建空目录（无法指导后续）；强行链接未经核查
Slint/wgpu（无法作为证据）。选用契约框架，不更换 Slint/wgpu/acadrust 技术方向。

影响：此次不会提供 APK/Web 可运行产物，不能声称满足规范 §12.3 的合成原型。
后续必须优先补证并锁定版本；不允许无限期将它留在待验证状态。接口允许通过后续 ADR 修订。
测试：本机 workspace、Wasm 核心、依赖边界与占位/权限/过期结果契约；平台运行单独验收。
