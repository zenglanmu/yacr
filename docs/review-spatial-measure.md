本轮两个子代理分别只写代码/回归测试，不执行编译、格式化或测试；

## 空间索引输入与原子失败

`GridSpatialIndex` 在 rebuild/update 修改状态前验证所有插入 bounds；
每轴须有限且 min ≤ max，零 extent 合法。非法输入返回 `InvalidInput`，
不会先删除旧条目或接纳部分插入。bounds/ray 查询即使索引为空也验证输入，
ray 复用精确拾取的 `validate_ray` 规则；有效空查询仍返回空结果。

新增 5 项合成契约覆盖：NaN/正负无穷/各轴倒置、拒绝 rebuild/update 后旧查询
保持一致、未构建/已构建空/非空索引的非法查询、零 extent 和方向阈值合法射线。
主控 `cargo test -p cad-spatial ... --locked` 实际为 **25 passed / 0 failed**。

## 角度归一化数值稳健性

`angle_at_vertex` 不再平方大坐标或计算两个长度的乘积。先以各臂最大分量
缩放，再用 hypot 求缩放后的范数，计算单位向量点积。即使臂长超出 f64
可表示范围，只要臂分量有限，仍可求出有效角度。退化阈值仍使用世界单位；
非有限点、相减溢出的臂、零臂与小于容差的臂显式拒绝，未改成假成功。

新增 6 项合成测试覆盖：0/45/90/135/180° 在 1 至 1e308 尺度不变、
分量为 f64::MAX 的三维臂、平面投影、退化和非有限输入。
主控 `cargo test -p cad-measure ... --locked` 实际为 **51 passed / 0 failed**。
