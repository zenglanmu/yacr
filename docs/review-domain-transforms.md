# cad-domain 数值变换正确性审查（2026-10-04）

## 范围与依据

仅修改 `crates/cad-domain` 的变换/单位辅助函数与合成契约测试，不增加依赖、不扩展几何功能、不修改其他 crate 或共享交接文档。
依据 `CAD_IMPLEMENTATION_SPEC.md` §3.3、§8.2、§16.1：CPU 使用 f64，未知单位不得假定毫米，极端尺度及嵌套变换需要契约覆盖。

## 修复

1. `Transform3::is_uniform_scale` 原来先平方原始系数，再除以尺度平方。有限的大尺度会产生 `inf / inf`，小尺度会产生 `0 / 0`，导致真正的均匀缩放被拒绝，极小非均匀缩放可能被接受。现在先按最大绝对系数归一化，再计算长度与正交性；保持原有相对容差尺度基准。
2. `max_scale` 原来通过 `f64::max` 忽略 NaN 系数，可能把无效线性矩阵报告为有限尺度。现在传播 NaN，并明确该函数返回最大绝对系数，而非任意变换的算子范数上界。
3. 相似变换判定拒绝负数/非有限容差，并在宽松容差下仍拒绝零列与归一化行列式恰为零的奇异矩阵。
4. `UnitContext::to_display` 原来把零、负数、NaN、无穷比例及溢出结果包装为 `Some`。现在只有有限输入、有限正比例、有限结果才返回 `Some`；未知/无效换算返回 `None`。保留负坐标/有向长度和零值的有效转换。

## 新增合成契约

`crates/cad-domain/tests/numeric_transforms.rs` 覆盖：

- 从 `1e-300` 到 `1e300` 的均匀缩放、镜像、非均匀缩放、剪切与斜角旋转；
- 每一个线性矩阵位置的 NaN，以及无效容差和宽松容差下的精确奇异矩阵；
- 含三维平移、非均匀缩放、镜像与剪切的组合应用顺序；
- 未知/无效单位比例、非有限输入、乘法溢出、合法有向值与极端有效比例。

## 限制与未闭环

- `max_scale` 仍保持最大绝对系数语义，不能保证任意旋转/剪切下的圆形范围上界；本轮没有修改其其他 crate 调用方。需要单独审查调用方是否把它当成最大伸长率。
- `apply_point` 仍是仿射变换，不进行齐次透视除法；公开矩阵可构造非仿射或非有限数据，本轮未增加完整矩阵验证 API。
- `determinant` 仍直接用原始系数计算，极端尺度可能溢出/下溢；本轮只避免相似判定依赖该原始行列式。
- 归一化行列式为零的检查不是条件数分析，接近奇异矩阵仍由容差策略决定；没有精确算术或鲁棒谓词保证。
- 单位转换仍以显式 `display_per_source` 为权威，不自动从单位枚举推导比例，也不诊断比例与枚举不一致。有限乘法下溢及正常 f64 舍入仍保留现有行为。
- 不包含真实 DWG、真实 GPU、浏览器、Android 或真机验证结论。
