## 本版变化 / What changed

### 命令覆盖 / Command coverage

- 完成“下一批 100 条”：99 条计入官方覆盖（`TRACE` 同名不同义，不计）；官方索引从 123 提升到
  **223 已实现（50 完整 + 173 部分）/ 758 未实现（共 981 条）**。
- 新增批次覆盖绘制/编辑、查询、图层、选择、文本与标注、视图/布局、工具/会话与界面命令；多数是
  声明的 v1 子集，界外显式拒绝。逐条边界见 `docs/autocad-2026-command-coverage.md`。

### 界面 / UI

- 功能区可收起为 AutoCAD-classic 菜单栏；五个面板可浮动；命令历史统一为固定栏 + 详情弹窗，可复制。
- 支持空白启动与 `CLOSE`；Shift 点击加入选择集；开始页与 About 对话框刷新。
- 移动端仍是同一棵 React 树，仅按宽度切换布局（`MOBILE_MAX_WIDTH = 1024`）。

### 天正 / vendor plugin

- `plugins/tch`（`tangent-ts`）作为 submodule 接入并进入所有载体产物；TCH 扩展到 22 个类。
- 插件管理器持久化；vendor 实体可选择并显示属性；修复动态块隐藏成员叠画；停止自动换行。

### 渲染与性能 / Rendering & performance

- 增量原地更新（LINE、圆弧/圆、移动实体、批次退役/追加、ChangeSet 驱动追加），导航 LOD、
  VRAM 预检与批处理。
- 渲染器自有瞬态光标覆盖层；绘制顺序 tie-break 固定并纳入契约测试。
- 显式偏好 WebGPU canvas；能力不足时拒绝，而不是静默降级。

### 文件与字体 / Files & fonts

- **Save As DWG**：写出新文件，覆盖源文件前警告；实验性导出走上游 acadrust `DwgWriter`。
- Web OPEN 走页面上传、SAVE/PLOT 走浏览器下载；Android SAF 打开/保存已接线。
- 打包 Noto CJK 回退字体与字体管理器。

### 构建与发布 / CI & release

- 新增 `publish-release.yml`：仅手工 dispatch，是唯一的发布入口。
- 签名使用仓库自签名材料（Android keystore、Flatpak GPG、Windows PFX、macOS ad-hoc），
  均非公共信任、未公证。
- 新增 fail-closed 子模块 gitlink 守卫与 acadrust 补丁台账门禁；发布资产不再污染受跟踪的 `assets/`。

### 修复 / Fixes

- 视口锚定到 DXF 视图中心；圆锥曲线裁剪；预览改为 `LineList` 段对，不再走重建路径。
- 修复矩形 `VPCLIP` 布局打开、`REVCLOUD` 重复出现在两个绘制面板、`MASSPROP`/`MEASUREGEOM`
  面板与契约对齐。
- 退出期 `corrupted double-linked list` 定位为 WebKitWebProcess 退出时拆除 EGL/GBM 的上游竞态；
  本项目未内置规避，也未掩盖。
