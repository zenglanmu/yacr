## 本版变化 / What changed

### 命令覆盖 / Command coverage

- 完成 2026-11-07 的“下一批 100 条”批次：**99/100 计入官方覆盖**，`TRACE` 按“同名不同义”
  （AutoCAD 2026 是协作追踪，本项目同名命令是旧式宽线带）不计入。
- 官方索引覆盖从 123 提升到 **223 已实现（50 完整 + 173 部分）/ 758 未实现**（共 981 条）。
  `CLOSE`（关闭当前唯一文档）以部分实现计入。
- 新增批次包含（均为**声明的部分实现 / v1 子集**，界外显式拒绝）：
  - 绘制/编辑：`DONUT` `SOLID` `HELIX` `MLINE` `MLSTYLE` `TREX` `EXTRIM` `MPEDIT` `DRAWORDER`
    `WIPEOUT` `POLYGON`（外切） `REVCLOUD`（对象模式 v1） `BOUNDARY` `TEXTTOFRONT` `OVERKILL`
    （v1 仅完全重复） `OOPS` `BREAKATPOINT` `REVERSE` `PEDIT`（v1 选项子集） `GRADIENT`
    `HATCHEDIT` `HATCHTOBACK` `HATCHGENERATEBOUNDARY` `SKETCH` `TRACE` `MOCORO` `MSTRETCH`
    `-PAN` `VIEWRES` `VSCURRENT` `REGEN3` `LINETYPE`
  - 查询：`MASSPROP` `MEASUREGEOM` `LIST` `STATUS` `FS` `AUDIT`
  - 图层：`LAYMCH` `LAYMGR` `LAYDEL` `LAYERSTATE` `LAYERPMODE` `LTSCALE` `LAYWALK` `LAYCUR`
    `LAYMCUR` `LAYFRZ` `LAYTHW` `LAYLCK` `LAYULK` `SETBYLAYER`
  - 选择：`QSELECT` `FILTER` `GETSEL` `SSX` `SELECTCOUNT` `FIND` `SELECTSIMILAR`、对象隐藏
  - 文本/标注：`JUSTIFYTEXT` `TJUST` `TSCALE` `TEXTALIGN` `TCOUNT` `TCIRCLE` `TEXTMASK`
    `TEXTUNMASK` `TORIENT` `TCASE` `TXT2MTXT`；`DIMSTYLE` `DIMTEDIT` `DIMEDIT` `DIMOVERRIDE`
    `DIMREGEN` `DIMDISASSOCIATE` `QDIM` `DIMROTATED` `DIMSPACE`；`GROUP` `UNGROUP` `GROUPEDIT`
    `QLEADER` `LEADER` `TEXTFIT` `HATCHSETBOUNDARY` `HATCHSETORIGIN` `XDLIST`
  - 视图/布局：`REDRAW` `REGEN` `VIEW` `VIEWGO` `VIEWBACK` `VIEWFORWARD` `VPOINT` `PLAN`
    `MODEL`；`LAYOUT` `VPORTS` `VPMAX` `VPMIN` `VPCLIP` `VPSCALE` `LAYVPI`
  - 工具/会话：`PURGE` `RENAME` `SETVAR` `TIME` `DBLIST` `TREESTAT` `MREDO` `MULTIPLE`
  - 界面命令：`ABOUT` `CLEANSCREENON` `CLEANSCREENOFF` `LAYERCLOSE` `PROPERTIESCLOSE`
- 覆盖计数只是**清单计数，不是 AutoCAD 兼容率**；未支持选项一律显式拒绝。逐条边界见
  `docs/autocad-2026-command-coverage.md` / `docs/compatibility.md`。

### 界面 / UI

- 功能区可收起为 **AutoCAD-classic 菜单栏**，收起时以菜单行承载同一批命令。
- **空白启动 + `CLOSE`**：不再强制打开图纸；开始页与 About 对话框刷新。
- 统一**命令历史**：固定栏 + 详细弹窗；命令历史可复制到系统剪贴板。
- **Shift 点击**加入现有选择集。
- 五个面板可**浮动**在绘图区之上。
- 诊断拆分为 **File info** 与 **Performance** 两个面板。
- 移动端仍是同一棵 React 树，仅按宽度切换布局（`MOBILE_MAX_WIDTH = 1024`）。

### 天正 / vendor plugin

- `plugins/tch`（`tangent-ts`）作为 git submodule 接入，插件 bundle 进入**所有载体产物**；
  TCH 扩展到 22 个类，含派生测量与 base-6 解码。
- 插件管理器**持久化**；vendor 实体可被选择并提供属性行。
- **动态块隐藏成员修复**：源文件 `invisible` 是烘焙显示状态，`*U231` 等匿名块不再把全部状态
  几何叠画；无激活状态的成员按烘焙 `invisible` 隐藏。
- 停止 TCH 自动换行（auto-wrap）。

### 渲染与性能 / Rendering & performance

- 渲染器自有**瞬态光标覆盖层**；瞬态覆盖层与 CAD base 解耦，消除闪烁。
- **增量原地更新**：LINE、圆弧/圆、移动实体、驻留批次退役/追加、ChangeSet 驱动的任意实体类追加。
- 导航 LOD、VRAM 预检、批处理；移除平移/缩放卡顿。
- 显式 **WebGPU canvas 偏好，缺失时拒绝**而不是静默降级；后端能力从设备 limits 推导。
- 绘制顺序 tie-break 固定到代码并纳入契约测试。

### 文件与字体 / Files & fonts

- **Save As DWG**：新文件写入，覆盖源文件前警告；实验性 DWG 导出走上游 acadrust `DwgWriter`。
- Web 端 OPEN 走页面上传、SAVE/PLOT 走浏览器下载；Android SAF 打开/保存已接线。
- 打包 Noto CJK 回退字体、Web 懒加载 CDN、字体管理器；每个载体一份 CAD 字体包。

### 构建与发布 / CI & release

- 新增 `publish-release.yml`：**仅手工 dispatch**，是唯一带 `contents: write` 的发布入口。
- 签名改为**仓库自签名材料**：Android keystore（缺失即失败，只发签名 APK）、Flatpak GPG、
  Windows PFX（配置时 `signtool`）、macOS 默认 ad-hoc。**均非公共信任，未公证。**
- 新增 fail-closed pre-push 子模块 gitlink 守卫；acadrust 补丁台账门禁。
- 排除 debug APK release job；发布资产 staged 到 `release-assets/`，不污染受跟踪的 `assets/`。

### 修复 / Fixes

- 视口锚定到 DXF 视图中心；圆锥曲线裁剪。
- 预览链展开为 `LineList` 段对，预览不再走重建路径。
- 矩形 `VPCLIP` 布局可打开；光标输入更平滑。
- `REVCLOUD` 同时出现在两个绘制面板；`MASSPROP`/`MEASUREGEOM` 合并后的面板与契约对齐。
- 退出期 `corrupted double-linked list` **已定位**为 WebKitWebProcess 在 atexit 拆除 EGL/GBM
  （Mesa）的上游竞态；主进程退出码仍为 `0`，本项目**未**内置规避、也未掩盖。

## 安装速览 / Install

```bash
# Linux（需要 org.gnome.Platform//51；有 .gpg 时用 --gpg-file 导入仓库公钥）
flatpak install --user yacr-0.1.5-linux-x86_64.flatpak
flatpak run dev.yacr.app
flatpak run --command=cad-cli-tools dev.yacr.app --help

# Windows：解压 zip，运行 bin/yacr.exe（未签名）
# macOS：解压 tar.gz，打开 Yacr.app（ad-hoc 签名、未公证）
# Android：adb install -r app-universal-release.apk
```

## 验证范围（诚实说明）/ Honest scope

- CI 只做**编译 / 打包 / 签名 / 上传**；**没有**真机、真实 GPU、视觉/像素或性能验收。
- Windows / macOS 运行时仍 **NOT VERIFIED**；Android 只有编译 + 签名验证，设备运行 **NOT RUN**；
  Web 冒烟是 **SwiftShader 软件渲染**，只作布局/DOM 证据，不是 GPU 或像素结论。
- 所有包**未公证、未上架商店**；Windows 本 run 未签名，macOS ad-hoc。
- 命令“已实现/部分实现”只表示路径存在并有契约测试，**不代表**与 AutoCAD 行为等价；本版
  新增的 99 条大多只到声明的 v1 边界。
- **没有**已验证的 DWG 兼容性矩阵；构建证据 ≠ 兼容性，详见 `docs/compatibility.md` 与
  `docs/handoff.md`。
