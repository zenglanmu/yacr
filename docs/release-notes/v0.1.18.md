## 本版变化 / What changed

### 命令覆盖 / Command coverage

- 完整实现的命令从 185 条增加到 **289** 条（部分实现 794 → 690，已实现合计仍 979/981）：这批只把
  「支持域内没有剩余可写缺口」的命令改成完整，每条都有契约测试。未支持选项仍按名拒绝；交互提示、
  系统剪贴板、多文档、绘图仪/CTB/STB 与三维装配属于全局范围，不算单命令缺口。

### 块属性与参照编辑 / Block attributes and reference editing

- `ATTDEF` 作为块成员实体、属性值存 `INSERT` 行内，随文档保存并与 DXF/DWG 往返；
  `ATTEDIT`/`ATTIPEDIT`/`GATTE`/`EATTEDIT`/`ATTSYNC`/`ATTREDEF`/`BATTORDER`/`ATTDISP` 可改值、
  排序与显隐，插入时的属性值按 `ATTDISP` 真正绘制。
- `REFEDIT`/`-REFEDIT`/`REFSET`/`REFCLOSE` 可在原图内编辑参照与块成员并写回。

### 编组与命名视图 / Groups and named views

- `GROUP`/`-GROUP`/`UNGROUP`/`GROUPEDIT` 的编组从会话内存迁入文档表 `tables/groups.json`
  （`.ymodel` minor 17），并按 `AcDbGroup` 在 DXF/DWG 往返；名称含空格时用引号寻址。
- `VIEW`/`-VIEW`/`VIEWGO`/`NEWVIEW` 的命名视图迁入 `tables/views.json`（minor 18），`NEWVIEW`
  支持 `<name>` 与 `WINDOW` 矩形取景，DXF/DWG 的 `VIEW` 表可读写；连续 pan/orbit 手势记入
  导航历史，`VIEWBACK`/`VIEWFORWARD` 仍是部分实现（ViewCube 拖拽与 pinch 没有结束信号）。

### 动作录制与应用域 / Action recorder and application domains

- 动作录制器可用：`ACTRECORD`/`ACTSTOP`/`ACTUSERINPUT`/`ACTUSERMESSAGE`/`-ACTUSERMESSAGE`/
  `ACTMANAGER` 录制可回放的宏（版本化外部 JSON，ADR-0056），Manage 面板直接驱动会话命令。
- 新增 `DOMAIN` 命令与应用域：`cad2d` 是唯一完整界面并带 AutoCAD 参考功能区，其余三域显式占位
  （隐藏功能区与命令行，不摆可点假按钮）；有文档时切换写文档，无文档只预览。

### 单位、时间与文档信息 / Units, time and document info

- `UNITS`/`-UNITS` 的存储格式（长度/角度格式、精度、基准角、旋向）现在驱动状态栏坐标、命令回显/
  日志与测量诊断的排版，不再是固定 4 位；`$INSUNITS` 插入缩放与 UNITS 对话框仍属全局范围。
- `SAVE` 的 `.ymodel` 写入单次读取的创建/最后更新时间并在打开时读回；`TIME`/`EDITTIME` 报告
  真实存储值（耗时、计时器与活跃编辑时长仍 NOT TRACKED）。
- `DWGPROPS` 写入真实文档摘要与自定义属性；`SYSVDLG` 支持 `SAVE|RESTORE <file.json>`（版本化
  `yacr.sysvar`）；`ACADINFO` 报告真实目标 OS/架构、单位/精度与应用域并明说「不写信息文件」。

### 图层与视口 / Layers and viewports

- `LAYLCK`/`LAYULK`/`LAYFRZ` 接受图纸空间与块拾取，`LAYFRZ` 写 `Vpfreeze`；
  `LAYCUR`/`LAYMCH`/`-LAYMCH`/`LAYMCUR` 扩到图纸布局与顶层 `INSERT`；`LAYERPMODE` 按 AutoCAD
  语义存进文档头，`LAYERP`/`LAYWALK` 的快照恢复与通配过滤补齐。
- `VPMAX`/`VPMIN`、`VPORTS` 标准视口配置与 `VPSYNC` 主视口同步可用；`LAYERSTATE`/
  `LAYERSTATESAVE` 仍是会话内快照（没有 DWG 命名层状态表与对话框）。

### 2D 编辑 / 2D editing

- 新增/补齐 `CHPROP`、`BREAKATPOINT`/`FLATTEN`、`TEXTALIGN`、`TCIRCLE`、`DONUT`、
  `HATCHGENERATEBOUNDARY`、`ADDSELECTED`、`GETSEL`、`MEASUREGEOM VOLUME`、
  `CENTERMARK`/`CENTERLINE`、`HATCH`/`-HATCH`（含 `.pat` 文件）、`HATCHEDIT`、`IMAGEATTACH`、
  `MIRROR`（`MIRRTEXT`）、`EXPLODE`（`EXPLMODE`）、`XPLODE`、`CDORDER`、`BTRIM`/`BEXTEND`、
  `DIMROTATED`、`DIMREASSOC`。
- `FINDINCLUDE`/`FINDMATCH`、`MULTIPLE`、`TFRAMES` 成为真实会话开关（块/参照搜索、比较方式、
  重复命令与图像/遮罩边框）；`TEXTSCR`/`GRAPHSCR`、`TRAYSETTINGS` 与 `-PURGE` 可用。
- 报告类：`BCOUNT` 覆盖整图与选择集，`DBLIST` 列出块定义成员与三个已建模空间，
  `JULIAN <YYYY-MM-DD>` 支持日历转儒略日，`ALIASEDIT` 的增删写入宿主 `preference.json`，
  `PAGESETUP`/`-PAGESETUP` 补齐 typed 写读。

### 3D 与天正 / 3D and Tianzheng

- 七种 3D 图元新增 AutoCAD 的 `Cube`/`Center+corner`/`Length` 选项形式并继续走既有精确 B-Rep；
  `PYRAMID` 支持 n 边形底与 `Top radius` 截断；`UNION`/`SUBTRACT`/`INTERSECT` 在提交前拒绝
  多壳/空壳结果，`XEDGES` 与 `3DORBIT`/`3DPAN`（`ORBIT`/`PAN` 别名）可用。
- 天正/探索者代理（ADR-0030 P0）：墙/洞/文字/块插入的版本无关语义写入 `.ymodel`
  `tables/vendor.json`（minor 12），重开由 `YANS` 重算；`openProgress`/`documentReady` 门禁在
  `SAVE`/`EXPORT`/`PLOT` 前生效。P1 其余类语义、copy hook 与 CLI 显式拒绝仍未实现。

### 兼容性 / Compatibility

- `.ymodel` 按文档内容取最小档位：块属性 14、`Text.mirrored` 15、二维约束保留 16、编组 17、
  命名视图 18；没有这些内容的文档仍写到更低的 4/5/7/8/9/10/11/12/13。v0.1.17 及更早读不了
  包含 minor 14+ 新表/新字段的归档，按 `ymodel.unsupported_minor` 拒绝。
- 二维约束求解器（ADR-0054）只接受了有界设计，P0 尚未开始；约束命令仍按名拒绝，不算本版能力。
