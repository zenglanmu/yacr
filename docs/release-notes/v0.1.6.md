## 本版变化 / What changed

### Android 取景 / Android framing

- **修复打开图纸文字过大（约 1.5×）**：Android 渲染目标必须是整窗 `SurfaceView`，但 tick 曾把
  **整窗**同时当成 canvas metrics 与 `session.render(logical)` 的取景尺寸；fit 使用整窗而不是
  可见矩形，图中内容被画得比可见区大。现在 `SurfaceMetrics` 新增 `origin`，
  `cad-ui-core::layout::window_surface_metrics` → `cad-host`（保留 origin）→
  `ViewSnapshot.canvas_origin` → `place_canvas_camera2d` 只平移正交相机中心；渲染目标仍是整窗。
  `origin = None` 的旧调用/GPU 契约逐位不变；3D 透视相机的离轴投影**未做**，记为 **Partial**。
- 共享契约测试覆盖 layout 映射/越界、放置数学、零偏移逐位相等、rect-local screen→world 对拍、
  快照校验与 `cad-host` 的 visible-rect fit。均为 host-target，无 GPU/像素断言。

### 字体 / Fonts

- **修复 SHX 大字体（CJK bigfont）字高解析**：`read_bigfont_metrics` 在 `strip_name` 之后又找
  NUL 并要求其后 ≥4 字节，真实 `gbcbig` / `hztxt` / `tssdchn` 等 info 块不满足，`height` 保持
  默认 **10**；这些字体的字形在约 100–127 单位 cell 中，`factor = size/height` 曾把 CJK 放大
  约 10×（`hztxt` 实测 12.2×、`gbcbig` 9.1×）。现在从 stripped info 开头读取 `above,below`
  （`height = above + below`），并补充两个不嵌入第三方字节的合成回归测试。
- `gbcbig` 的字形仍比其声明 cell 高约 1.38×（bytecode 归一化待单独核对），记为 **Partial**。
  本版未做真实字体 / AutoCAD golden 对照。

### 落地页 / Landing site

- 宣传页新增编号 `A` 的实机截图区块与大图纸指标（“725K 图元、展开后”口径），截图来自真实
  Linux Wayland 运行（NVIDIA Quadro P620 / Vulkan / wgpu），不是渲染图。
- 页面/README 平台措辞改为：Linux/Wayland 是主开发目标；Windows/macOS 是真实宿主但运行时与
  视觉验收待补；Android APK 已由维护者侧载运行（非 CI 验收）。
- 新增 `python3 scripts/test-landing-site.py` 契约（文件/清单 schema、截图资产、部署脚本
  fail-closed 片段、`site.yml` 手动触发约束），已接入 `core-quality`。

## 安装速览 / Install

```bash
# Linux（需要 org.gnome.Platform//51）
flatpak install --user yacr-0.1.6-linux-x86_64.flatpak

# Windows：解压 zip，运行 bin/yacr-windows.exe
# macOS：解压 tar.gz，打开 Yacr.app（ad-hoc 签名、未公证）
# Android：adb install -r app-universal-release.apk
```

## 验证范围（诚实说明）/ Honest scope

- CI 只做**编译 / 打包 / 签名 / 上传**；**没有**真机、真实 GPU、视觉/像素或性能验收。
- Windows / macOS 运行时仍 **NOT VERIFIED**；Android 只有编译 + 签名验证，设备运行 **NOT RUN**；
  Web 冒烟是 **SwiftShader 软件渲染**，只作布局/DOM 证据。
- 所有包**未公证、未上架商店**；Windows 视 secret 配置可能未签名，macOS ad-hoc。
- 没有已验证的 DWG 兼容性矩阵；构建证据 ≠ 兼容性，详见 `docs/compatibility.md` 与
  `docs/handoff.md`。
