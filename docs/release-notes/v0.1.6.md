# yacr v0.1.6

构建来源 / Source: `CI build layers` run for tag `v0.1.6`；资产由
`.github/workflows/publish-release.yml` 附加。

发布日期 / Released: 2026-11-09

包内版本与产物文件名均为 `0.1.6`。

## 本版变化 / What changed

### Android 取景 / Android framing

- 修复打开图纸文字过大（约 1.5×）：fit 现在按可见矩形取景，渲染目标仍是整窗；`origin = None`
  的旧调用逐位不变。3D 透视相机的离轴投影未做，记为 `Partial`。

### 字体 / Fonts

- 修复 SHX 大字体（CJK bigfont）字高解析：从 stripped info 读取 `above + below`，不再默认 10，
  消除约 10× 放大（`hztxt` 实测 12.2×、`gbcbig` 9.1×）。
- `gbcbig` 字形仍比其声明 cell 高约 1.38×，记为 `Partial`；未做真实字体 / AutoCAD golden 对照。

### 落地页 / Landing site

- 新增实机截图区块与 725K 图元指标；截图来自真实 Linux Wayland 运行，不是渲染图。
- 平台措辞改为：Linux/Wayland 主开发；Windows/macOS 运行时待验收；Android 维护者侧载运行。
- 新增 `scripts/test-landing-site.py` 契约并接入 `core-quality`。

### 文档 / Docs

- 移除已退役 UI 工具包的遗留命名，去掉过时措辞与背书免责声明。
