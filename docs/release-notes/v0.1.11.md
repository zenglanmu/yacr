## 本版变化 / What changed

### 命令补齐 / Command completion

- `-LAYER` 从只读报告升级为完整命令行写形式：`NEW/MAKE/SET/RENAME/DELETE/ON/OFF/FREEZE/THAW/LOCK/UNLOCK/COLOR/LTYPE/LWEIGHT/PLOT`；名单逗号分隔、含空格的值可加双引号；整行原子、一条事务/一步撤销。裸 `-LAYER`/`-LAYER ?` 仍是只读报告。
- `ZOOM` 新增 `OBJECT`（当前选择的包围盒；模型空间展开块成员，图纸空间只接受可直接寻址的实体）与 `nX`/图纸空间 `nXP`；`ZOOM DYNAMIC` 仍是按名拒绝。
- View → navigate 增加 `ZOOM OBJECT` 按钮；`nX`/`nXP` 保持命令行形式。
- DWG 保存选择器在写入前提示“实验性、写新文件、绝不覆盖源图纸”。
- 覆盖清单：981 条命令中 **823 条有实现路径（68 完整 + 755 部分）**；未支持选项按名拒绝。

### 显示修复 / Display fixes

- Linux 原生 Wayland 5K/scale=2：CAD 子表面尺寸改为只按 DOM 分区矩形取整一次（`physical_content_size`），不再因与 GTK allocation 差 1 像素而拒绝每一帧、让 CAD 区透出桌面。
- Windows：DirectComposition 路径明确使用 DX12；持久化的 `wgpu_backend=vulkan` 会得到明确错误，而不是透明窗口。先前设置为 `vulkan` 的用户请改为 `auto` 或 `dx12`。
- 右侧导航坞改为浮在绘图区右缘，不再占用 CAD 分区宽度；绘图区横跨整个工作区，浮动面板仍显示在导航坞之上。
