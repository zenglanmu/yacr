## 本版变化 / What changed

### 网格建模 / Mesh modelling

- **导入的 SketchUp 网格保留源面身份**（`skp:face:*`，源面序号）：同一个源面下的三角形可按面区域选中、
  移动与推拉，不再只能对整实体操作；没有面身份的网格按 `mesh.face_identity_unavailable` 拒绝。
- **`UNION` / `SUBTRACT` / `INTERSECT` 现在也接受网格实体**（`AcDbSubDMesh`）：纯 Rust
  `manifold-rust` 内核在后台 worker 执行，结果必须闭合，写回一条网格行、一次事务、一步撤销。
  精确实体仍走精确内核；精确体与网格混合选择按 `boolean.operand_class_mismatch` 拒绝，不静默
  三角化。文档替换或关闭会中止后台任务，陈旧结果不写库。
- **新增 `MESHREPAIR`（朝向修复）与 `MESHREBUILD`（绕向重建）**：只接受闭合网格，开放壳层仍按
  `mesh.not_closed` 拒绝；修复结果带 `Partial` 报告。
- **网格编辑**：面区域 `MOVE`（自动生成侧壁）与 `PRESSPULL`（沿区域外法向），三角形边 `MOVE`；
  `MESHREFINE` 做 1→4 细分，`MESHSMOOTH` 做边界固定的 Laplacian 平滑。每次编辑一次事务、
  一步撤销，丢失的法线/UV/材质等派生属性直接丢弃，不伪造。
- **`MESHCAP` 补边界环**：平面环直接补；非平面环投影到最佳拟合平面后补并报告 `non_planar`；
  多个独立环分别补；共面嵌套环按包含深度成组，外环以直接内环为孔补成环带（annulus），
  深度 2 的岛独立补。自交/退化环、同向绕行或找不到可见桥的嵌套组按名拒绝并保持开口。
- **载体**：只有 Linux 原生 `native-below` 注入网格内核；Windows/macOS/Android 与
  `dom-canvas`（Web、X11/XWayland）按 `unsupported-runtime: mesh-modeler` 显式拒绝。

### DWG / DXF

- **打开 DWG/DXF 固定回到标准平面视图**，不再自动进入等轴测；被复用的 3D 视口也会重置。
- **修复缩放/旋转块参照里 ATTRIB 文字的二次变换**：属性按文件绘制坐标导入、按块坐标导出，
  复杂样本的图界从约 2.7e8 降到约 5.3e5 单位。

### 浏览器 / Web

- **页面载体从欢迎页开始**：未打开文件时显示 `StartPanel`（最近文件与恢复快照），首次 `OPEN`
  原地替换空文档，不再显示编译内置的合成模型。
- **`dom-canvas` 接通标准视图与 orbit**：`hostProfile` 声明 7 个标准视图与 `orbit`，ViewCube 的
  视图和轨道由 wasm 会话执行；未选择 3D 视图时 2D orbit 仍按会话理由拒绝。

### 内核 / Kernel

- **`solidcore` 固定内核更新到上游 `f17599cb`**（727 个提交）：适配角点不支持/面过大错误，
  扫掠 `Status(1001)` 按 `solid.extrude_profile_failed` 拒绝；圆角契约与 G2 混合面同步。
