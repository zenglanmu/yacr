构建来源 / Source: `CI build layers` run [`42959255569`](https://github.com/zenglanmu/yacr/actions/runs/42959255569)（tag `v0.1.10`）；资产由

发布日期 / Released: 2026-11-11

## 本版变化 / What changed

### 主题 / Theme

- 标题栏与移动端顶栏新增 sun/moon 切换：深色/浅色即时生效、写入本地偏好并在重启后保持；
  `cad_status.theme` 是唯一权威（`dom-canvas` 的本地缓存不会覆盖原生宿主）。
- 浅色主题有完整的界面配色（功能区、面板、状态栏、对话框）。CAD 画布保留图纸里的颜色，
  浅色背景下**近白**线条/圆弧/网格/文字改用黑色；饱和色可能仍偏浅——这是显示映射的已知边界，
  不是自动反色。
- 未做：跟随系统主题、浅色主题下的出图/导出背景。

### 最近图纸 / Recent drawings

- 开始面板列出最近 10 个**成功打开**的图纸（最新在前、按路径去重），点击即可重开；打开与另存
  的文件选择器从上次打开图纸的目录开始。
- 只有成功打开才记录；失败/取消不记录。Web 载体显式拒绝并返回空列表，不伪造历史。
- 紧凑布局（窄窗口/移动端）仍不显示开始面板，因此最近图纸只在桌面宽布局可见。

### 右侧导航坞 / Right navigation dock

- ViewCube 与导航栏停靠在绘图区右缘，朝向来自宿主真实相机（3D/2D、正交/透视），随视图实时
  更新；立方体隐藏时导航栏仍在，2D 视口下也可用。
- `NAVBAR`、`NAVVCUBE`、`NAVVCUBEDISPLAY 0-3`、`DISPLAYVIEWCUBEIN2D/3D` 都是真实的持久化设置，
  命令行、界面按钮与 `preference.json` 三处一致。
- 未做：罗盘与边/角目标、切换动画、`NAVVCUBE PROPERTIES` 对话框（仍按名拒绝）。

### 修复 / Fixes

- 背景色变化（例如切换主题）现在立即重绘，不再等到下一次平移/缩放才生效。
- `NAVBAR`/`NAVVCUBE`/`NAVVCUBEDISPLAY`/`DISPLAYVIEWCUBEIN2D`/`DISPLAYVIEWCUBEIN3D` 这五个
  界面设置选择子能通过命令门禁真正入队（此前在入队前被拒绝）。

### 错误报告 / Error reporting

- 运行期错误弹出可复制的详情（消息、位置、堆栈），支持历史前后切换；React 渲染崩溃后弹窗仍然
  存活，状态栏红字可点开同一条详情。
- 浏览器版 wasm panic 走同一个弹窗上报；属性面板默认宽度 220 → 280px（上限 460px）。
