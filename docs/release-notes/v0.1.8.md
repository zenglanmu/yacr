## 本版变化 / What changed

### AutoCAD 2026 命令覆盖 / Command coverage

- 981 条官方命令中有实现路径的从 423 提升到 **623（66 完整 + 557 部分）**。本轮新增 Wave 9–16
  共 200 个名字；多数是只读报告或稳定的具名拒绝，不代表 AutoCAD 兼容。
- 2D 编辑：新增 `ARRAY`/`-ARRAY`/`ARRAYCLASSIC` 阵列路由，`BLEND`、`BREAKLINE`，
  `-BLOCK`/`-INSERT` 等别名，以及 `-BOUNDARY`/`-HATCH`/`-HATCHEDIT`/`EXOFFSET` 的部分形式。
- 图层与布局写入可撤销：`LAYDEL`/`-LAYDEL`、`LAYMRG`/`-LAYMRG`、`LAYFRZ`、`LAYLCK`、`LAYULK`、
  `LAYTHW`、`RENAME`/`-RENAME`、`LAYERSTATE RESTORE`，以及 `LAYOUT NEW/RENAME/DELETE`、
  `LAYOUTMERGE`、`LAYOUTWIZARD`、`VPORTS`/`-VPORTS`、`VPCLIP RECT`、`VPSCALE` 均为一条事务、一步撤销。
- 页面设置与视口：`PAGESETUP`/`-PAGESETUP` 写入 Authored `PLOTSETTINGS`，`PSETUPIN` 复制已存设置，
  `MVIEW` 创建矩形视口；`LAYVPI` 按视口冻结/隐藏图层，不改全局层表。
- `HATCHEDIT` 的 `ADDBOUNDARIES`/`REMOVEBOUNDARIES` 真实修改填充边界；`DIMTEDIT` 增加字形级
  LEFT/RIGHT/CENTER 对齐；`JOIN` 可把椭圆弧与线/弧/多段线/样条焊成一条有理 B 样条。
- 3D 实体、曲面/网格、图像/PDF/DGN 底图等未实现命令按稳定原因显式拒绝，不会静默成功。

### 显示栅格 / Display grid

- model-space 栅格改为 AutoCAD 式主/次两级：主格间距 5，次线随缩放自适应；次线比主线更淡，
  整体弱于图线。
- 栅格默认关闭。F7/`GRID` 只切会话开关；Options 的 Grid 勾选会同步会话开关并写入偏好。
- 新建空白图使用可读的默认平面尺度，并在无模型范围时用 2D 视口矩形绘制参考栅格/坐标轴，
  不再出现整屏粗十字或红色 bounds 提示。

### 下载与文档 / Downloads and docs

- 发布下载默认走 `dl-yacr.snakeheartgo.top` CDN，GitHub Release 仍作为回退链接。
- 开始页、关于对话框、README、落地页与历史发行说明移除平台验收免责长文；证据边界集中在内部
  文档，功能不变。
