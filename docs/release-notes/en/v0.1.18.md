# yacr v0.1.18

Source: `CI build layers` run
[`45431680053`](https://github.com/zenglanmu/yacr/actions/runs/45431680053) (tag `v0.1.18`); the
assets are attached by `.github/workflows/publish-release.yml`.

Released: 2026-11-24

## What changed

### Command coverage

- Fully implemented commands went from 185 to **289** (partial 794 → 690; the implemented total is
  still 979/981). This batch only promotes commands with no remaining writable gap inside their
  supported scope, and every one has contract tests. Unsupported options are still refused by name;
  interactive prompts, the system clipboard, multiple documents, plotters/CTB/STB and 3D assemblies
  are global scope, not per-command gaps.

### Block attributes and reference editing

- `ATTDEF` is a real block member and attribute values live on the `INSERT` row; they persist with
  the document and round-trip through DXF/DWG. `ATTEDIT`/`ATTIPEDIT`/`GATTE`/`EATTEDIT`/`ATTSYNC`/
  `ATTREDEF`/`BATTORDER`/`ATTDISP` edit values, order and visibility, and inserted values are drawn
  according to `ATTDISP`.
- `REFEDIT`/`-REFEDIT`/`REFSET`/`REFCLOSE` edit references and block members in place and write the
  result back.

### Groups and named views

- Groups (`GROUP`/`-GROUP`/`UNGROUP`/`GROUPEDIT`) moved from session memory into the document table
  `tables/groups.json` (`.ymodel` minor 17) and round-trip as `AcDbGroup` in DXF/DWG; names that
  contain spaces are addressed with quotes.
- Named views (`VIEW`/`-VIEW`/`VIEWGO`/`NEWVIEW`) moved into `tables/views.json` (minor 18).
  `NEWVIEW` accepts a name or a `WINDOW` rectangle, and the DXF/DWG `VIEW` table is read and written.
  Continuous pan/orbit gestures are recorded in the navigation history; `VIEWBACK`/`VIEWFORWARD`
  remain partial (ViewCube drags and pinch have no end signal).

### Action recorder and application domains

- The action recorder works: `ACTRECORD`/`ACTSTOP`/`ACTUSERINPUT`/`ACTUSERMESSAGE`/`-ACTUSERMESSAGE`/
  `ACTMANAGER` record replayable macros (versioned external JSON, ADR-0056), and the Manage panel
  drives the session commands.
- New `DOMAIN` command and application domains: `cad2d` is the only complete interface and ships an
  AutoCAD reference ribbon; the other three domains are explicit placeholders (ribbon and command
  line hidden, no fake clickable buttons). Switching writes the document when one is open and only
  previews otherwise.

### Units, time and document info

- Stored `UNITS`/`-UNITS` formats (length/angle format, precision, base angle, direction) now drive
  the status-bar coordinates, command echo/log and measurement diagnostics instead of a fixed four
  decimals; `$INSUNITS` insertion scaling and the UNITS dialog remain global scope.
- `SAVE` stamps the `.ymodel` with a single-read created/last-updated time and reads it back on open;
  `TIME`/`EDITTIME` report real stored instants (elapsed/timer and active edit time are still NOT
  TRACKED).
- `DWGPROPS` writes real document summary and custom properties; `SYSVDLG` supports
  `SAVE|RESTORE <file.json>` (versioned `yacr.sysvar`); `ACADINFO` reports the real target OS/arch,
  units/precision and application domain, and states that it does not write an information file.

### Layers and viewports

- `LAYLCK`/`LAYULK`/`LAYFRZ` accept paper-space and block picks and `LAYFRZ` writes `Vpfreeze`;
  `LAYCUR`/`LAYMCH`/`-LAYMCH`/`LAYMCUR` extend to paper layouts and top-level `INSERT`s; `LAYERPMODE`
  is stored in the document header with AutoCAD semantics; `LAYERP`/`LAYWALK` add snapshot restore
  and wildcard filters.
- `VPMAX`/`VPMIN`, `VPORTS` standard configurations and `VPSYNC` master-viewport sync work;
  `LAYERSTATE`/`LAYERSTATESAVE` remain session-only snapshots (no DWG named layer-state table or
  dialog).

### 2D editing

- Added or completed `CHPROP`, `BREAKATPOINT`/`FLATTEN`, `TEXTALIGN`, `TCIRCLE`, `DONUT`,
  `HATCHGENERATEBOUNDARY`, `ADDSELECTED`, `GETSEL`, `MEASUREGEOM VOLUME`, `CENTERMARK`/`CENTERLINE`,
  `HATCH`/`-HATCH` (including `.pat` files), `HATCHEDIT`, `IMAGEATTACH`, `MIRROR` (`MIRRTEXT`),
  `EXPLODE` (`EXPLMODE`), `XPLODE`, `CDORDER`, `BTRIM`/`BEXTEND`, `DIMROTATED` and `DIMREASSOC`.
- `FINDINCLUDE`/`FINDMATCH`, `MULTIPLE` and `TFRAMES` became real session switches (block/xref
  search, comparison mode, repeated commands, image/wipeout frames); `TEXTSCR`/`GRAPHSCR`,
  `TRAYSETTINGS` and `-PURGE` are available.
- Reports: `BCOUNT` covers the whole drawing and selections, `DBLIST` lists block-definition members
  and all three modelled spaces, `JULIAN <YYYY-MM-DD>` converts calendar dates, `ALIASEDIT` add/remove
  persists to the host `preference.json`, and `PAGESETUP`/`-PAGESETUP` gain typed reads and writes.

### 3D and Tianzheng

- The seven 3D primitives accept AutoCAD `Cube`/`Center+corner`/`Length` option forms on the existing
  exact B-Rep; `PYRAMID` gains an n-gon base and `Top radius` truncation; `UNION`/`SUBTRACT`/
  `INTERSECT` reject multi-shell or empty results before commit; `XEDGES` and `3DORBIT`/`3DPAN`
  (aliases of `ORBIT`/`PAN`) work.
- Tianzheng/TSSD proxies (ADR-0030 P0): version-independent wall/opening/text/block-insert semantics
  are written to `.ymodel` `tables/vendor.json` (minor 12) and recomputed via `YANS` on reopen;
  `openProgress`/`documentReady` gates run before `SAVE`/`EXPORT`/`PLOT`. P1 semantics for the
  remaining classes, the copy hook and the explicit CLI refusal are still unwritten.

### Compatibility

- `.ymodel` picks the minimum tier per document: block attributes 14, `Text.mirrored` 15, 2D
  constraints reserved 16, groups 17, named views 18; documents without those features are still
  written at the lower 4/5/7/8/9/10/11/12/13. v0.1.17 and earlier cannot read archives that contain
  the new minor-14+ tables/fields and refuse them with `ymodel.unsupported_minor`.
- The 2D constraint solver (ADR-0054) only has an accepted bounded design; P0 has not started, so
  constraint commands still refuse by name and are not a capability of this release.
