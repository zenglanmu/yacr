发布日期 / Released: 2026-11-01

## 本版变化 / What changed

- **Tauri v2 capability 修复**：四个宿主新增最小 `core:event:allow-listen` /
  `core:event:allow-unlisten`，修复 push-only `cad_event` 被 ACL 拒绝导致的命令全部禁用。
- **Android NDK 链接修复**：关闭 `ndk` 的 `nativewindow` feature（该 stub 只有 API ≥ 26），
  恢复 `minSdkVersion = 24` 的 APK 构建。
