# yacr v0.1.4

构建来源 / Source CI run: [`41307807752`](https://github.com/zenglanmu/yacr/actions/runs/41307807752)
(tag `v0.1.4`, all jobs green). The assets are the workflow artifacts of that run,
attached by `.github/workflows/publish-release.yml`.

发布日期 / Released: 2026-11-01

## 本版变化 / What changed

- **Tauri v2 capability 修复**：四个 Tauri 宿主（Linux/Windows/macOS/Android）新增最小
  `core:event:allow-listen` + `core:event:allow-unlisten` capability。此前的 push-only
  `cad_event` 流被 ACL 拒绝（`Command plugin:event|listen not allowed by ACL`），表现为命令全部
  禁用、CAD 层透明露出桌面。
- **Android NDK 链接修复**：关闭 `ndk` 的 `nativewindow` feature——它无条件链接
  `-lnativewindow`，而该 stub 只有 API ≥ 26 才有，本应用 `minSdkVersion = 24`。Android APK
  恢复可构建。

## 安装速览 / Install

```bash
# Linux（需要 org.freedesktop.Platform//26.08）
flatpak install --user yacr-0.1.2-linux-x86_64.flatpak
flatpak run dev.yacr.app
flatpak run --command=cad-cli-tools dev.yacr.app --help

# Windows：解压 zip，运行 bin/yacr.exe（未签名）
# macOS：解压 tar.gz，打开 Yacr.app（未签名、未公证）
# Android：adb install -r app-universal-debug.apk
```
