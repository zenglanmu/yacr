发布日期 / Released: 2026-11-14

## 本版变化 / What changed

### 插件 API / Plugin API

- TypeScript 二次开发接口可用：`cad_api_status` 描述能力，`cad_api_call` 提供只读访问
  （活动文档、文档列表、`database.revision`、`database.symbolTables`、`editor.currentSelection`），
  `cad_api_submit` / `cad_api_poll` 提供写通道与 `transaction.commit`。能力表 17 行 =
  16 supported + 1 pending（`document.lock`）。
- 插件可装载并注册自己的命令，插件命令与 CAD 命令分表，处理异常只产生
  `plugin.command.failed` 通知。
- 插件提示（点、实体、文本、关键字）在命令行内回答；提示期间命令行为数据输入，Esc 取消。
  `editor.writeMessage` 在客户端回显，不伪造宿主行。

### 视图与导航 / View and navigation

- 视图立方改为 canvas 软件投影的 3D 立方体（背面剔除、画家排序、平面着色，标签不镜像），
  拖拽经新 IPC `cad_orbit` 真实旋转相机；点击六个面仍是标准视图。
- 六个面保留 `sr-only` 真实按钮，键盘与读屏仍可操作；取不到相机或 2D 上下文时显示明确的
  不可用态而不是空白。
- 导航 dock 重排：收起/展开移到立方体正下方；窄屏变为“立方体 + 一个展开图标”的浮动卡片，
  开合不改变卡片宽度。

### 触控板缩放 / Trackpad pinch

- Linux 原生 Wayland：触控板 pinch 缩放 CAD 视图，不再缩放网页。
- Windows / macOS：精确触控板的 `ctrl`+wheel 与 `gesturestart/change/end` 汇到同一 CAD 缩放，
  Safari 15+ 的双信号按一次手势只缩放一次。
- Android 关闭 WebView 页面缩放，两触点 pinch 走 CAD。

### 导入 / Import

- 新增 SketchUp `.skp` 预览导入（16 种可打开格式）。
- Revit 预览保留多材质构件的透明度（取构件内最透明材质）；导出器选择的 alpha 由
  `import.rvt.alpha_chosen` 诊断说明，不再整块回退为不透明。

### 系统集成 / OS integration

- OS 级“用 Yacr 打开”注册到 15 个扩展 / 21 个 MIME 类型：Flatpak `.desktop`、AppStream、
  `shared-mime-info` 包，Android 22 条 `fileAssociation`，macOS `Info.plist`。
  Windows 产物仍是 zip、无安装器，注册表关联保持 NOT IMPLEMENTED。

### 修复 / Fixes

- 折线解码的字段寻址错误（此前任何折线都无法解码）。
- Web 载体在 canvas 会话启动前也回答 `cad_api_status`。
