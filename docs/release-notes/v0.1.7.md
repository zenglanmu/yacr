# yacr v0.1.7

构建来源 / Source: `CI build layers` run for tag `v0.1.7`；资产由
`.github/workflows/publish-release.yml` 附加。

发布日期 / Released: 2026-11-09

包内版本与产物文件名均为 `0.1.7`。

## 本版变化 / What changed

### 应用内更新检测 / In-app update detection

- 启动后读取 `https://yacr.pages.dev/downloads.json`，有新版本时显示非模态提示：可打开下载页、
  跳过此版本或稍后；每天最多检查一次。网络或解析失败只记为不可用，不谎报“已是最新”。
- 新增 `cad_app_version`（native 回答原生版本，wasm 回答产物版本）与 `cad_open_release_page`
  （固定打开下载页、不接受 URL 参数）；Android 暂无 opener，返回稳定拒绝并提供复制链接。
- 落地页 `/downloads.json` 增加 CORS；四个 Tauri `tauri.conf.json` 与 web harness 的
  `connect-src` 增加 `https://yacr.pages.dev`。
- “跳过此版本”与 24 h 节流保存在 `localStorage`，不进入 CAD 设置，也不阻塞 CAD 输入。

### 落地页 / Landing site

- 下载区重做：版本 hero、四平台卡片（体积、签名状态、CDN/GitHub 链接、SHA-256、安装命令）。
- 新增更新日志时间线（`changelog.json`），由 `scripts/build-landing-changelog.py` 从本目录生成，
  并在 CI/部署中做新鲜度校验。
