## 本版变化 / What changed

### 兼容性 / Compatibility

- **v0.1.16 及更早保存的 `.ymodel` 本版打不开**：条目从 deflate 改为 zstd 帧后 `format.read`
  必须等于 2，旧归档按 `ymodel.unsupported_version` 拒绝；请重新导入源文件。写入 minor 按内容取
  4/5/7/8/9/10/11，minor 6 是可打开的只读旧档。

### BIM 语义与查询 / BIM semantics and query

- IFC（`Partial`）导入楼层、类型、材质、PSet 与数量集；RVT（`Unverified`）映射同样字段（单样本
  的代码契约观察）；DGN（`Unverified`）只有 tags/Item Types 组成的 PSet，不推断楼层/类型/材质。
- 属性面板展示固定 BIM 行与逐条 PSet 动态行，直接可寻址的标量属性可编辑；BIM 面板按类别/楼层/
  类型/材质/属性过滤（桌面浮窗、窄屏底部抽屉），点击行可选实体。
- IFC4 导出回写楼层、类型、材质、PSet 与 `contains`/`nests` 关系；其它关系不导出并按 kind 报告，
  不写成容器或嵌套冒充。

### 参数化 / Parameters (Partial)

- 参数表、表达式（四则/幂/函数/条件）与配置覆盖随 `.ymodel` 保存；用户可用的写入只有属性面板的
  `param.<name>`，`PARAM` / `PARAM CONFIG` 只有命令层（无 UI/传输路径）；特征求值、几何传播、
  `Insert.scale` 与文本模板仍未实现（具名拒绝）。

### 3D 显示与渲染 / 3D presentation

- 打开 3D 文档默认等轴测；`FIT` 保持视角并把轨道中心落在模型中部；透视缩放围绕光标做 dolly；
  方位球可点可选、可拖拽环绕。
- 网格基色纹理（UV0）从 glTF 与 SketchUp（仅正面）导入，带 mip + 各向异性与 REPEAT 采样；
  metallic/roughness/normal/emissive/occlusion 来自 glTF（RVT 只有按材质名推测的标量，无贴图/
  UV）。两者随 `.ymodel` 保存并按通道渲染，glTF 导出回写同一组通道。
- 程序化 HDR 天空 + ACES 色调映射只作用于 PBR 网格（旧光照路径逐字不变），`IBL` 开关默认开；
  新增 MSAA 设置（off/2x/4x，默认 4x，设备不支持时下调并记录）。
- 网格线框按表面边界绘制，不再显示三角剖分对角线。
- 无头 `render` 可从真实 3D 相机出图：`--view` 预设或 `--azimuth` / `--elevation` / `--fov`。

### 保存与导出 / Saving and exporting

- `SAVE` 在 Linux/Windows/macOS/Android 上恒写 `.ymodel`（Web 按 `unsupported-runtime: ymodel`
  拒绝）；其它格式走独立的 `EXPORT`。覆盖已有文件时上一版留在 `.bak`（Android 仅在 provider 能
  建备份时，否则提示 `save.no_backup`；首次写出不产生备份）。
- 打开 DWG/DGN/SKP/RVT 等反向或未验证格式时给出一条提示，可在设置里全局关闭（“不再提示”；
  Web/X11 的 `dom-canvas` 该设置是内存态）。
- `.ymodel` 条目用 zstd 帧压缩（真实语料缩小 16%–67%）；可选打包字体/参照/图片，并新增自定义
  字体目录设置（仅 `native-below`；Web 与 X11/XWayland 的 `dom-canvas` 不可用）。

### 导入边与测量 / Imported edges

- SketchUp 的真实边随导入成为显示边；可选的端点/中点吸附与测量声明为 `Partial`（只对存边的
  实体）。
- SKP 导出把多个源合并进一个 run，修复只写第一个实体的问题；自由边可写出，实体分组压平
  （`export.skp.entity_grouping_flattened`）与 mesh 体存储边不复制都逐实体报告。

### 浏览器与界面 / Web and UI

- 部署的浏览器模块只编入 DWG/DXF 连接器（28 MB → 11.7 MB，`web-build` 曾因超过 25 MiB 单文件
  上限连续失败）；其它格式按名拒绝。桌面 X11/XWayland 的 `dom-canvas` 仍保留全部格式。
- ≤1024 px 紧凑布局去掉顶栏，绘图区从视口第一像素开始；属性面板改为底部抽屉并随绘图区自适应；
  方位球、菜单按钮与导航卡按安全区排布。
- 已正确打开的图纸不再因显示近似（如 `$PDMODE 0` 的点画成 `+`）弹出宿主错误横幅；近似诊断仍
  保留在场景诊断里。
