# UI 功能实现迭代（2026-10-04）

## 第五轮：固定 AutoCAD 默认键位映射

用户要求：把一套固定（不可重绑定）的 AutoCAD 默认键位接到**已存在**的命令/开关上；
对尚无后端能力的按键给出显式“不支持”反馈，不得静默无操作；保留
`interaction.keyboardShortcuts` 门控；不引入重绑定编辑器。

键字符串为 Slint 私有，故键位表放在 `crates/cad-ui-slint/ui/app.slint` 现有捕获/冒泡
处理器内，Rust 只把动作分发到既有回调。新增 `shortcut-unsupported(string)` 回调与双语键
`shortcut.unsupported`，在 `adapter.rs` 把稳定标签（如 `F4`、`Ctrl+S`）渲染到状态栏并展开
命令行。

| 键 | 实际接入 | 限制 / 诚实替代 |
| --- | --- | --- |
| F7 | 网格叠加开关（复用 `overlay-toggled("grid", …)`） | 经配置存储生效，非本地影子状态 |
| F3 | 捕捉提示**标记叠加**开关（`overlay-toggled("snapHints", …)`） | 只是标记叠加，**不是**运行对象捕捉 OSNAP 开关——该能力尚不存在 |
| F2 / Ctrl+9 | 展开/收起命令行 | 只是既有命令/状态行的高度切换，**不是**完整命令历史浏览器，也不改变命令行可见性；两者均受 `command-visible` 门控 |
| Ctrl+1 | 侧栏/面板开合 | 是侧栏，**不是**属性选项板本身 |
| Ctrl+0 | 净屏：新增 `clean-screen`，布局统一改读 `chrome-visible = application-ui && !clean-screen` | 只隐藏 chrome，不隐藏画布；默认 `false` 时与 `application-ui` 等价，既有布局不变 |
| F1、F4–F6、F8–F12、Ctrl+N/S/Shift+S/P/C/X/V | 显式 `shortcut-unsupported`（本地化文案） | 后端能力留待后续阶段；现在**显式报告**，绝不静默或伪造成功 |

保留的既有键位：Ctrl+O（受 `can-open` 门控）、Ctrl+Z、Ctrl+Shift+Z、Ctrl+Y、Ctrl+A、
Ctrl+Home、Escape 的优先级不变。文本编辑器仍优先处理本地撤销/重做/全选/剪贴板/光标移动：
Ctrl+Z/Y/A/C/X/V 与 Ctrl+Home 留在冒泡处理器，其余（F 键、Ctrl+O、Ctrl+1/9/0、Ctrl+N/S/P）
在捕获处理器。整表仍由 `application-ui && keyboardShortcuts` 门控，且不吞掉 Alt/Meta。

已知限制（F2）：不支持反馈渲染在命令行/状态栏 chrome 中，而 Ctrl+0 净屏会隐藏 chrome，
故净屏下按 Ctrl+S 会把文案写入 `status_label` 却**不可见**。这是已记录的限制，不宣称为
可见反馈；本轮不新增画布内 toast。

证据边界：本轮实际运行（本机 Wayland + Quadro P620；离屏用软件 Vulkan lavapipe）：
`cargo fmt --all`、`cargo clippy -p cad-ui-slint --all-targets --locked -- -D warnings`、
`VK_ICD_FILENAMES=…/lvp_icd.json cargo test -p cad-ui-slint --locked`（171 通过 / 0 失败，
含 137 lib + 34 集成）、`python3 scripts/check-i18n.py`、`python3 scripts/check-workflows.py`。
新增/强化合成契约：`shortcut_map_contract.rs`（源码结构契约：捕获/冒泡分别绑定、唯一缩进
声明、chrome 门控计数）与 `shortcut_map_wiring.rs`（adapter 运行时：F7 翻转配置网格叠加、
Ctrl+9/Ctrl+0、净屏下 Ctrl+S 的本地化文案与 chrome 隐藏）。这些均为合成/离屏证据，不代表
真实窗口、真实 GPU、浏览器或真机；未做键位焦点、无障碍或跨平台键盘验收。

## 第四轮：补全导航、选择全部与批注搜索

三个独立分支任务曾因额度限制中断，首次没有代码交付；恢复后分别完成补全导航、
应用层 SelectAll 和批注搜索。子代理仅写代码，主控审查、提交、合并并完成接线。

- 参考 15：有建议时上下键只移动高亮，没有建议时才召回历史；Tab 填入高亮项或
  第一项，已高亮时第一次 Enter 只填入、第二次 Enter 提交。模型变化清除旧索引，
  高亮暴露 checked 元数据，并通过共享滚动偏移使键盘选中项进入三行建议窗口。
  修改键组合和关闭快捷键时不接管文本编辑器本地操作。
- 参考 15 / F05：属性面板、`SELECTALL` 和冒泡的 Ctrl+A 复用只读应用命令。
  Viewer/Work 均可选择当前模型空间可枚举对象，保留完整 INSERT 路径和实体 ID，
  按叶对象及祖先 INSERT 的真实图层/会话覆盖过滤；失败时保留旧选择，不修改底图。
  纸空间、不透明几何、嵌套 compound INSERT、循环/深度截断或无法解析的动态状态
  显式拒绝，不返回不完整的“全部选择”成功。文本编辑器优先处理自身 Ctrl+A。
- 参考 13 / F07、F09：桌面与手机批注管理提供文字/类型的大小写不敏感子串搜索、
  清除和独立无匹配提示，保留权威原始行索引以精确路由选择、删除、显隐命令。
  完整批注文本采用只读可复制编辑器，拒绝辅助技术写入且保持模型绑定。
  模型替换后重算匹配数；此功能不修改文字、不提供查找替换或原始 CAD 编辑。

限制：SelectAll 是整个对象选择，不新增网格面选择，也没有独立源实体 hidden 字段；
不保证导入前丢失的可见性信息。使用既有拾取枚举和 SelectionSet，未做大图性能验收。
键盘、建议滚动、搜索布局、剪贴板与辅助技术运行均未验证。

新增 27 项合成契约：SelectAll 17、批注面板源码 6、搜索匹配 1、UI 接线 1、
补全导航新增 2；同时强化既有补全及历史源码契约。全部仅编译，未执行。
首次 debug 编译拒绝跨条件组件访问滚动控件 ID；主控改用共享偏移属性绑定并重编译。
最终统一代码树实际执行 `cargo fmt -p cad-app -p cad-ui-slint` 和
`cargo check --workspace --exclude app-android --exclude app-web --all-targets --locked`，
检查通过（49.80 秒），包含 Linux App、Slint 与新增测试代码。
本轮未运行测试、静态门禁、clippy、wasm/Android 编译、Linux 离屏、release 构建、
真实图纸/GPU/窗口/浏览器/真机或远程 CI；首次失败记录不改写成通过。

## 第三轮：命令补全与批量图层显隐

三个独立分支分别实现纯 Rust 补全、Slint 建议控件、应用层批量显隐命令；
子代理仅写代码，主控审查、提交、合并、接线并统一 debug 编译，不执行测试。

- 参考 15：按当前已支持的完整命令选择器前缀给出建议，规范化大小写和 Unicode
  空白；最多 8 项、输入预算 4096 UTF-8 字节，Viewer 隐藏 Work-only 操作。
  已完整输入的选择器不再建议自身；不猜测路径、坐标、自由文本或未支持命令。
  点击或启用快捷键后的无修改键 Tab 只填入命令并返回输入焦点，仍须 Enter 提交。
  模式切换清除旧建议，下次编辑按新模式重算；Escape 先关闭可见建议，再处理工具取消。
- 参考 11 / F03：桌面与手机图层面板加入“显示全部图层/隐藏全部图层”，目标是整个
  权威图层顺序，不是搜索命中的子集；每次只发送一个真实应用命令。
  `SetLayerVisibilities` 在发布前校验文档、完整 LayerId、重复 ID 和空批次；失败不留下
  部分覆盖，成功以 clone/update/swap 一次发布会话覆盖。保留无关覆盖，不改数据库
  flags/revision、不重解析底图，不宣称 DWG 图层编辑或撤销支持。
- 主控接入双语补全/批量操作标签、失败反馈和精确 ID 映射；UI 不乐观修改派生图层
  行，渲染状态仍由宿主真实执行后推送。单图层显隐也校验当前文档/目标存在性。

限制：补全没有模糊匹配、别名排名、建议上下键导航、命令帮助或自动执行；上下键
仍用于历史召回。建议采用有界浮层，未做真实焦点、移动端尺寸或遮挡验收。
批量覆盖克隆增加瞬时内存，不将编译通过当作大图性能证据。
输入召回/补全/按钮操作和批量原子性的新契约仅编译，运行结果仍为 NOT RUN。

新增 22 项合成契约：补全逻辑 7、补全控件源码 3、批量显隐应用集成 11、
补全/批量回调接线 1。主控审查时修正一项补全断言：完整 `ZOOM IN` 不应再建议自身。
最终统一代码树已实际执行 `cargo fmt -p cad-app -p cad-ui-slint` 和
`cargo check --workspace --exclude app-android --exclude app-web --all-targets --locked`，
debug 检查通过（50.61 秒），包含 Linux App、Slint 与新增测试代码。

## 第二轮：命令召回与只读详情

三个独立分支分别实现纯 Rust 命令历史、Slint 历史控件、属性/诊断详情。
子代理仅写代码，主控审查后提交、合并并补齐配置/双语/模型接线；不执行测试。

- 参考 10/15：保存已提交命令的原始大小写与内容，连续重复去重，提供上下键召回、
  开始召回时保存输入草稿、返回最新项之后恢复草稿，以及清空历史。
  展开命令行可滚动查看并选择/复制每条已提交输入；不把输入记录当作执行成功记录。
  上下键服从有效快捷键配置，不接管修改键组合或文本框本地撤销。
  历史最多 50 条，单条上限 4096 UTF-8 字节、总文本 64 KiB；旧条目按时间淘汰。
  超长输入显式拒绝归档并显示双语提示，不截断后再召回成另一条命令。
  预算只覆盖历史文本，不覆盖正在编辑的输入草稿或完整 UI 内存。
- 参考 11 / F05：属性值不再只能查看截断文本；完整真实值用只读编辑器展示，支持
  选择、复制、换行及滚动，保留混合值、空选择与清除选择行为。
- 诊断 / U08、N01：诊断视图不再混入普通面板，展示实际 severity、code、description、
  object、details，使用真实空状态文案，不以标题替代无数据说明。
- 主控修正只读编辑器的辅助技术写入口：拒绝写入且不重设 text，避免赋值破坏
  真实模型绑定后使后续属性或诊断更新成为陈旧内容。

限制：历史仅记录已提交命令，不包含完整输出/错误档案；每条单独选择复制，没有
跨条复制按钮、可调历史高度、自动补全或空闲 Enter 重复命令。属性与诊断编辑器并非
CAD 属性编辑功能。未运行键盘、剪贴板、辅助技术或移动端布局验收。

新增 26 项合成契约：纯 Rust 历史 18、历史控件源码 3、属性/诊断源码 4、
adapter 历史/语言接线 1。源码契约不能证明焦点、复制、只读控件或布局运行正确。
主控首次 debug 编译发现命令输入同时指定 width/min-width；移除矛盾声明后重编译。

主控合并后的最终代码树实际执行 `cargo fmt -p cad-ui-slint` 和
`cargo check --workspace --exclude app-android --exclude app-web --all-targets --locked`。
最终检查通过（47.37 秒），包含 Linux App、Slint 和新增测试代码；不将首次编译失败
记录改写成通过。第二轮未运行契约测试、静态门禁、clippy、wasm/Android 编译、
Linux 离屏、release 构建、真实图纸/GPU/窗口/浏览器/真机或远程 CI。

## 第一轮：命令选择器、图层搜索与快捷键

### 范围与实施方式

本轮从 `docs/ui-requirements/10-statusbar-and-commandline.md`、
`11-properties-and-docks.md`、`15-command-input-and-selection.md` 补齐可直接接入现有
命令/数据库派生模型的交互。功能参考不是源码移植要求；原始图元编辑、DWG 回写、
参数化建模等不因参考文档列出而成为本项目必须交付的功能。

三个子代理分别在独立 worktree/分支修改命令输入、图层面板和快捷键代码。
子代理不编译、不执行测试、不格式化、不提交；主控审查、合并后统一 debug 编译。
现有并发修改不纳入本轮提交，不覆盖。

### 第一轮实现

| 参考分册 / 本项目需求 | 实际接入 | 限制 |
| --- | --- | --- |
| 10、15 / 命令输入 | 统一大小写及 Unicode 空白；测量、批注、标准视图、导航、选择、导入导出命令复用现有回调；短别名尊重配置 | 不解析坐标、路径或脚本；未知输入保留原文；空提交仅确认活动工具，不冒充重复上一条命令 |
| 11 / F03 图层查询 | 桌面 dock 与手机 sheet 共用大小写不敏感子串搜索、清除及无匹配提示；原始模型索引保留 | 只过滤派生视图，不改变数据库或重解析底图；未新增全开/全关、图层编辑或状态管理器 |
| 15 / F02、F08 交互 | Ctrl+O、Ctrl+Z/Y/Shift+Z、Ctrl+Home、F2、Escape；随有效配置实时启停，撤销重做受模式及可用性限制 | F2 仅展开已有命令行，不是完整历史；文本框保留本地撤销与光标移动；Escape 按优先级取消当前交互 |
| 16 / 无障碍 | 共享按钮公开本地化标签和 disabled 状态，支持辅助技术默认操作及 Space/Enter 激活，焦点边框可见 | 未验证屏幕阅读器或真实键盘窗口；不宣称整体 WCAG 合规 |

命令输入为不可用撤销/重做给出现有双语错误，而不当作未知命令或成功操作。
图层搜索通过 `layer_search::refresh` 在搜索变化及宿主替换模型后重算匹配数量，
不会因切换图纸沿用旧数量；过滤不缩短权威模型，避免点击映射到错误 LayerId。
搜索文案在两份 catalog 中同步，切换语言经同一 chrome 管线更新。

新增 12 项合成契约：命令输入 5、图层面板源码 3、搜索匹配 1、键盘交互 1、
按钮源码 2；另新增 1 项 adapter 搜索/配置接线契约。源码字符串契约只保证接线形状，
不能证明运行行为。键盘交互契约包含离屏调用，但本轮仅编译，未执行任何离屏操作。
