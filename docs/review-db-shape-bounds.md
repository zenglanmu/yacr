# SHAPE 实例包围盒审查（2026-10-04）

`BoundsAccumulator` 的 SHAPE 分支预乘实例缩放后，又通过球体包围盒帮助函数重复乘缩放。
实例放大时包围盒过大，缩小时包围盒过小，可能影响适应图纸和候选筛选。
修复为仅向帮助函数传入局部尺寸，由帮助函数统一变换中心并应用一次缩放。

新增合成契约 `shape_bounds_apply_instance_scale_once`，覆盖 0.25 倍缩小、2 倍放大与平移，
期望值保留既有 Frobenius 范数的保守膨胀，而非声称获得精确球面边界。
这里只修复既有保守尺寸估算的重复缩放，不声称 SHX 字形真实轮廓边界或剪切变换已精确验证。
