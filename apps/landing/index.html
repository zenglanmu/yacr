01

Rust core

文档、几何、命令与渲染的唯一权威；场景、显示表示与像素都由它派生。 The single authority for documents, geometry, commands and rendering. The scene, the display representation and every pixel are derived from it.

02

React interface

所有载体共用同一个 React + TypeScript 包，按宽度切换，不按构建目标分叉。 One React + TypeScript package for every carrier, switching by width rather than by build target.

03

Document owner

native-below 由原生会话持有文档，dom-canvas 由 wasm 会话持有；没有第二份文档状态，也没有静默回退。 Native sessions own the document on native-below; the wasm session owns it on dom-canvas. No second document state, no silent fallback.

native-below

Linux Wayland · Windows · macOS · Android

native 会话持有 cad-db。透明 WebView 在上，原生 CAD surface 在下。 The native session owns cad-db. A transparent WebView sits above the native CAD surface.

dom-canvas

X11 / XWayland · Web

wasm 会话持有 cad-db，CAD 画在 DOM <canvas> 上。 The wasm session owns cad-db; CAD is drawn on a DOM <canvas>.

不是同一份文档状态在两边共享。共享的是契约与 UI，不是数据；另一侧不得实例化第二份文档状态。 The same document state is not shared across both. Contracts and UI are shared; data is not. Neither side may instantiate a second document state.

08 HIGHLIGHT

.ymodel — 自己的文档格式 .ymodel — a document format of its own

zip 容器，每个建模条目是一帧 zstd 承载的分片 JSON，外来条目按字节原样保留。保存只重编码被改动的分片，未触及的条目从上一份归档按压缩字节复制，写入以原子替换落盘。字体、外部参照、图片与 BIM 定义可以随文档一起走。 A zip container where each modelled entry is one zstd frame of sharded JSON, with foreign entries preserved byte-for-byte. Saving only re-encodes the shards that changed; untouched entries are raw-copied from the previous archive and the file is replaced atomically. Fonts, external references, images and BIM definitions can travel with the document.

ZIPZSTDSHARDED JSONATOMIC SAVE

    07常见问题FAQ

    几个直接的问题。 Straight answers.

    关于许可、成熟度、技术取舍与下载的边界，都在这里。 Licensing, maturity, technical trade-offs, and download boundaries — answered without hedging.

    还有问题？去 GitHub IssuesStill curious? Open a GitHub issue ↗
    yacr 免费吗？Is yacr free?

    是。yacr 以 AGPL-3.0 发布，源码公开在 GitHub。没有付费版本，也没有被锁住的导出功能。 Yes. yacr is released under AGPL-3.0 and the source is public on GitHub. There is no paid tier and no locked export feature.

    现在能当生产 CAD 用吗？Can I use it as a production CAD tool today?

    还不能。项目处于活跃开发的预览阶段：可以打开 DWG/DXF/DGN 与常见网格格式、查看 2D/3D、测量并编辑二维图形；请自留副本。 Not yet. The project is in an active-development preview stage: it can open DWG/DXF/DGN and common mesh formats, view 2D/3D, measure, and edit 2D geometry — keep your own copies.

    为什么界面用 React 而不是 Rust UI 工具包？Why is the interface React instead of a Rust UI toolkit?

    因为界面要覆盖桌面、移动与浏览器。一套 React + TypeScript 界面由同一套组件与布局规则驱动，Rust 核心继续作为唯一数据源；换来的不是第二套 UI，而是一个界面覆盖五种载体。 Because the interface has to cover desktop, mobile and the browser. One React + TypeScript interface is driven by the same components and layout rules while the Rust core remains the single data source — so there is no second UI, just one interface across five surfaces.

    支持 DWG 保存吗？Does it support saving DWG?

    没有 DWG 原地回写。原生格式是 .ymodel：SAVE 始终写 .ymodel，其它格式用 EXPORT 导出为新文件，不会覆盖源文件。 There is no in-place DWG writeback. The native format is .ymodel: SAVE always writes .ymodel, and other formats go through EXPORT as a new file — never overwriting the source.

    命令覆盖 979/981 是什么？What does 979/981 command coverage mean?

    它是命令清单的计数：981 条命令中 979 条有实现路径（185 完整 + 794 部分），其余 2 条（MEASURE / TRACE）按同名不同义不计入。它不是 AutoCAD 兼容率；未支持的选项会按名称拒绝，不会静默成功。 It is a count of the command list: of 981 commands, 979 have an implementation path (185 complete + 794 partial); the other 2 (MEASURE, TRACE) are counted as same-name-different-meaning. It is not an AutoCAD compatibility rate. Unsupported options are rejected by name, never silently accepted.

    国内怎么下载？How do I download from mainland China?

    优先使用 Cloudflare R2 镜像；GitHub Release 是上游与校验来源。镜像文件与上游同名，下载后用 .sha256 校验即可。若 CDN 未配置，下载按钮会自动回退到 GitHub。 Prefer the Cloudflare R2 mirror; GitHub Releases are the upstream and checksum source. Mirror files keep the upstream filenames — verify them with the .sha256 file after downloading. If the CDN is not configured, buttons fall back to GitHub automatically.
