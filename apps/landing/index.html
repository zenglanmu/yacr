01架构Architecture

Rust 是核心，
但不是全部。 Rust at the core.
Not the whole story.

yacr 的文档、几何、命令和渲染核心是 Rust；界面是 React + TypeScript，运行在 Tauri WebView 中。不是 100% pure Rust，这是为了“一棵 React 树，多种载体”的有意取舍。 yacr’s document, geometry, command, and rendering core is Rust. The interface is React + TypeScript running inside a Tauri WebView. It is not 100% pure Rust — a deliberate trade-off for one React tree across many surfaces.

同一棵 React 树覆盖桌面与移动，按宽度切换，不按构建目标分叉。 One React tree covers desktop and mobile, switching by width rather than by build target.

03

Native surface

native-below 用原生会话，dom-canvas 用 wasm 会话；两条路径各自持有文档。 Native sessions for native-below; wasm sessions for dom-canvas. Each path owns its document.

native-below

Linux Wayland · Windows · macOS · Android

native 会话持有 cad-db。透明 WebView 在上，原生 CAD surface 在下。 The native session owns cad-db. A transparent WebView sits above the native CAD surface.

dom-canvas

X11 / XWayland · Web

wasm 会话持有 cad-db，CAD 画在 DOM <canvas> 上。 The wasm session owns cad-db; CAD is drawn on a DOM <canvas>.

不是同一份文档状态在两边共享。共享的是契约与 UI，不是数据；另一侧不得实例化第二份文档状态。 The same document state is not shared across both. Contracts and UI are shared; data is not. Neither side may instantiate a second document state.

    几个直接的问题。 Straight answers.

    yacr 免费吗？Is yacr free?

    是。yacr 以 AGPL-3.0 发布，源码公开在 GitHub。没有付费版本，也没有被锁住的导出功能。 Yes. yacr is released under AGPL-3.0 and the source is public on GitHub. There is no paid tier and no locked export feature.

    现在能当生产 CAD 用吗？Can I use it as a production CAD tool today?

    还不能当生产 CAD。项目处于活跃开发的预览阶段：可以打开 DWG/DXF、查看 2D/3D、测量，但 DWG 兼容性、真实图纸、vendor 与性能验收都未完成；请自留副本。平台运行时边界见上方平台卡片。 Not yet. The project is in an active-development preview stage: it can open DWG/DXF, view 2D/3D, and measure, but DWG compatibility, real drawings, vendor entities, and performance acceptance are all unfinished — keep your own copies. Platform runtime boundaries are in the platform cards above.

    为什么 UI 用 Web 技术而不是纯 Rust？Why use web tech for the UI instead of pure Rust?

    因为界面要覆盖桌面、移动与 Web。一棵 React 树可以由同一套组件和布局规则驱动，Rust 核心继续作为唯一数据源。代价是它不是 100% pure Rust；这是有意的取舍，不是遗漏。 Because the interface has to cover desktop, mobile, and the web. One React tree can be driven by the same components and layout rules while the Rust core remains the single data source. The cost is that this is not 100% pure Rust — a deliberate trade-off, not an oversight.

    支持 DWG 保存吗？Does it support saving DWG?

    没有 DWG 原地回写。SAVE 目前是有损 DXF 另存；源文件是 DWG 时，会写出一个实验性的新 DWG 文件，而不是覆盖原文件。 There is no in-place DWG writeback. SAVE is a lossy DXF Save As today; when the source is DWG, it writes an experimental new DWG file instead of overwriting the original.

    命令覆盖 223/981 是什么？What does 223/981 command coverage mean?

    它是命令清单的计数：981 条命令中 223 条有实现路径（50 完整 + 173 部分），758 条未实现。它不是 AutoCAD 兼容率；未支持的选项会按名称拒绝，不会静默成功。 It is a count of the command list: of 981 commands, 223 have an implementation path (50 complete + 173 partial) and 758 are not implemented. It is not an AutoCAD compatibility rate. Unsupported options are rejected by name, never silently accepted.
